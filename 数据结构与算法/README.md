# 数据结构与算法

数据结构与算法课程的手写练习合集（C++）。每个 `.cpp` 是一个独立的小程序，覆盖顺序表、链表、栈、队列、树、排序与查找等基础内容。

## 目录

### 顺序表
- `顺序表 - 初始化.cpp` —— 顺序表基本初始化
- `顺序表- 动态分配内存地址初始化.cpp` —— 动态分配内存的顺序表

### 链表
- `链表.cpp` —— 单链表基本操作
- `双向链表.cpp` —— 双向链表的插入 / 删除 / 遍历

### 栈
- `栈.cpp`、`栈 实验.cpp`、`栈-实验.cpp`、`栈-实验2.cpp` —— 顺序栈练习
- `栈的链式结构.cpp` —— 链栈实现
- `利用字符栈检查表达式的括号是否匹配.cpp` —— 括号匹配
- `利用顺序栈将十进制整数转换为二进制数.cpp` —— 进制转换

### 队列
- `队列.cpp`、`队列实验.cpp`、`顺序队列.cpp` —— 顺序队列
- `队列-链式结构.cpp` —— 链式队列

### 树
- `二叉树.cpp` —— 二叉树的建立与遍历

### 排序与查找
- `冒泡排序和选择排序 练习.cpp`
- `基于冒泡排序的学生成绩稳定排序.cpp` —— 稳定排序的应用
- `对字母进行排序.cpp`
- `按规则排序.cpp`
- `除首尾字符外降序排序.cpp`
- `电话簿排序.cpp`
- `归并排序和堆排序.cpp`
- `折半查找.cpp` —— 二分查找

### 综合应用
- `停车场管理.cpp` —— 栈 + 队列的经典综合题
- `b.cpp` —— 杂项练习

## 编译运行

任意一个文件都可以单独编译：

```bash
g++ "栈.cpp" -o stack
./stack
```

Windows 下编译产生的 `.exe` 已在 `.gitignore` 中排除，仓库只保留源码。
